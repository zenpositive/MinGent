MinGent - what changed
======================

Version 1.1.4 beta
- The status line says what the agent is doing ("Thinking", "Reading
  parser.py", "Writing the answer") and no longer shows the words of its
  thoughts. Those are inside the steps.
- No text that shows up and goes away again: text is shown in the chat only
  once it will stay. Short notes before a step stay inside the steps, and an
  answer that MinGent is about to send back for testing or for a review
  waits there too.
- The answer is about the task, also after a review. When the independent
  review finds nothing, the agent's own answer is shown as it is and the
  line of steps ends with "reviewed". When it finds problems, the agent
  fixes them and writes a new answer about the whole task. You never have
  to open the steps to understand the answer.
- The agent can schedule tasks when you ask: add, change, pause, remove and
  list. MinGent shows you the name, the time and the whole instruction and
  waits for your OK before anything is saved, also in Full auto.
- Restricted programs: a new switch in Settings > Agent > Tools, off by
  default. With it on, the agent can work in your own browser, File
  Explorer, terminals, code editors, mail and chat programs and Windows' own
  tools when you ask for it, after your OK for each program in each chat.
  With it off, the agent tells you about the switch instead of just saying
  no. Password managers, money and remote-access programs, the Store,
  Windows' sign-in and admin prompts, the Windows Security app and MinGent
  itself stay off limits either way.
- Task Manager and other programs that run as administrator: the agent now
  says that Windows keeps them out of its reach and does the job another
  way, for example ending a program with a command. Before, it opened Task
  Manager and then could not find it.
- The agent knows MinGent: it is told where README.txt is and which
  Settings page has what, so it can answer how to set something up.
- The web console is used only when a task needs it: for something the
  other browser tools can't show, or when it takes clearly fewer steps.
- The token figures for the tool groups in README.txt were out of date;
  they now match what Settings shows.

Version 1.1.3 beta
- Using your PC: the agent can open a program by its Start menu name, such
  as Calculator or Excel, and work in it. It does this when its file,
  command and browser tools can't do the job, or when using the program is
  the natural way. MinGent asks first and shows the agent's reason; the OK
  lasts until the chat ends. Browsers, terminals and File Explorer are
  refused with a pointer to the agent's own tools. Mail, chat, password
  managers, money and remote-access programs and Windows' own tools are
  never handed to the agent.
- Seeing its windows together: a model that can see images can get all the
  windows it may use in one picture, each where it is on the main screen.
  Your other windows, the taskbar and the desktop are never in the picture.
- "Programs you opened yourself" in Settings > Agent > Tools is now on, so
  the agent can ask for a program you already have open. The asking is as
  before: for each program, in each chat, also in Full auto, and the same
  programs stay look-only or are never offered. The question now shows the
  agent's reason, and names a Store app as the Start menu does. Switch it
  off there if you don't want to be asked.
- One answer per task: what the agent says before MinGent sends it back to
  work (to test its changes, to finish its checklist, or for the
  independent review) folds into the line of steps. The chat shows one
  final answer instead of two or three messages that each read like the
  end, and a click on the line still shows all of it.
- One status line while it works: the second line, which showed a piece of
  what the agent last wrote, is gone. What it writes on the way stays
  inside the steps.
- Independent review: a small change is reviewed by reading only when the
  agent ran nothing or its checks ended well, so the reviewer asks you for
  nothing. For bigger work it reads first and re-runs only the checks that
  matter. It leaves the page that is open for you in the browser as it is.
- Fewer needless reminders: an answer that says what the agent can do
  ("I'm an AI agent that works on this PC"), or one like "I can't say which
  is better for your use case", no longer counts as a refusal. An answer
  that already says the code was not run is not sent back to be tested.
- The agent and its helpers are told not to run a command for what the file
  tools do, such as reading a file or counting lines, since those never
  wait for your OK.
- System tools the agent starts itself (the Store, Process Explorer, the
  performance monitor and the like) are off limits to it, the same as when
  you have them open. Nothing can be written into the Start menu folders.
- Choosing a folder opens the Explorer-style folder window instead of the
  small old tree: for a chat's folder, the default folder and the folder
  for models.
- When a saved API key is rejected, a new chat says the key was not
  accepted and offers to check it, instead of the first-run screen.
- A shortcut that Windows refuses is not kept: the old choice comes back
  and Settings opens at the shortcuts.
- A command picked from the / list with Enter no longer leaves a line
  break in the message box.
- An answered question shows its whole title again ("Ready to start?"); on
  Windows it was cut to "R...".
- Thought titles drop lead-ins such as "The user wants", so a title reads
  "A bar chart", and keep the # of C#.
- A scheduled task waits five minutes without input, instead of one,
  before it takes over while a chat is open in front of you.
- Settings > Scheduled: the hint for Day fits the chosen "How often", and
  Delete is off for a task that isn't saved yet.
- The question for a site no longer says "for this chat" above a button
  that allows it once. When the agent is refused a program you had open,
  it tells you which switch allows it.

Version 1.1.2 beta
- Skills: a skill is a how-to for a job that comes up again, written once as
  a Markdown file. Type / in the message box and your skills show up next to
  the commands. /skill starts a new one in Notes, and you can ask the agent
  to save what it just did as a skill. The agent gets one line per skill and
  reads the file when a task matches. Skill folders made for Claude (a
  folder with SKILL.md) work too.
- Scheduled tasks: Settings > Scheduled (or /schedule) sets up tasks that
  MinGent starts by itself while it is open: every day, Monday to Friday,
  every week, every month or once. Each run is a new chat named after the
  task, started when the agent is not busy and you are not in the middle of
  something in MinGent. A run missed while MinGent was closed is made up
  for once. Only you can add or change them.
- Projects: the folder button at the top of a chat shows where the chat
  works and lets you choose a folder for it (or /project). MinGent
  remembers the folders you choose, lists them above your chats, and a
  click on one shows only its chats and starts new chats in it. A chat
  keeps its folder, and a scheduled task can run in a project.
- Watching videos: a model that can see images can look at a video. The
  agent opens it in the browser (the video's page, such as a YouTube page,
  or an MP4, WebM or MOV file on your PC) and gets pictures of it: nine
  moments on one sheet, each with its time, or up to four moments it picks
  as full pictures.
- Charts: the agent can put a bar or line chart into its answer, and
  MinGent draws it in the chat.
- The status line says what is happening this moment. While the model
  thinks, it shows what the thought is about instead of the word Thinking,
  and the steps are titled the same way. What the agent last said to you
  shows under the line while it works. The window title shows the plan's
  current step, or that the agent is waiting for you.
- A shortcut from any program: Settings > General > Keyboard shortcuts has
  "Bring up MinGent from any program". With Ctrl+Alt+Space, Alt+Shift+Space
  or Ctrl+Alt+Enter chosen there, that shortcut brings MinGent to the front
  with the message box ready. It is off until you choose one.
- Giving a file to a page: the agent can put a file from your PC into a
  page's file field, for example to attach it to a form. MinGent asks you
  first and names the file and the site.
- Close-ups: when something in a program's window is too small to read in a
  screenshot, the agent can look at one part of the window enlarged.
- The agent uses a project's AGENTS.md (or CLAUDE.md), the file many coding
  agents read for how to build, test and write code in a project. MinGent
  tells the agent where the file is, and the agent reads it before it
  changes the project's code, so it costs one line of context until then.
- The agent's files no longer open in Notes by themselves. "Show the files
  the agent writes" in Settings > Agent is off unless you switch it on. The
  chat shows each change and links to the file.
- Before the agent runs code in the browser console, the question says in
  plain words what the code does, instead of only "Run code on <site>" and
  the code. MinGent reads the code itself and names what matters, such as
  reading cookies or form fields, sending requests to another site, changing
  the page or leaving code running. When the agent says what the code is
  for, that shows first and "MinGent's reading" under it, so a description
  can't hide what the code does.
- The final answer comes after the independent review. When the agent says
  it is done and a review of its changes comes next, the chat says so right
  under that message, so it isn't taken for the final answer. The final
  answer after the review covers what the review found. If the review can't
  finish, the agent says so in its final answer instead of the task ending
  without one.
- The agent types words and commands into games and other programs in one
  go instead of pressing one key per letter, and it opens a game's chat or
  command box first.
- The chat says when MinGent sends the agent back to work, for example
  because the checklist still has open items or changed code wasn't tested.
  Before, the agent's message looked like the end and then the work went on
  without a word.
- In a question from the agent, the row for your own answer no longer shows
  a blinking cursor before you click it. It shows a steady one until then.
  What you type before clicking goes to the message box, which answers the
  question the same way.
- Console check: a property named like a keyword (x.function, x.class,
  x.var) no longer hides the call on the next line from the check, and a
  long run of spaces after url( no longer slows it down.
- When Anthropic's model list can't be loaded, the built-in list offers
  Claude Fable 5.2.

Version 1.1.1 beta
- The agent no longer stops after 200 steps. It works until the task is done
  or you press Stop. MinGent still stops it when it keeps repeating itself or
  running into the same problem.
- While the agent uses a program, it waits before each click, key press,
  scroll or mouse move until you have left the mouse and keyboard alone for a
  second (four seconds at most), so it doesn't take over the mouse and
  keyboard in the middle of your own scrolling and typing. If you press Stop
  while it waits, it doesn't go ahead.
- Typing and key presses in a program stop as soon as another window comes
  to the front, instead of after up to 15 more characters, so they don't go
  to the window you switched to. The same goes for Enter after typed text.
- The agent can move the mouse by a set amount, the way a hand moves a real
  mouse, so it can look around in 3D games that turn the view with the mouse.

Version 1.1.0 beta
- With Claude, OpenAI, Gemini or OpenRouter, the file reads, file searches
  and page reads the agent asks for in one step run at the same time, and the
  agent can send an explorer to research in the background while it keeps
  working. The explorer's report shows up in the chat, and the agent waits
  for it before its final answer. Local models work as before.
- Searching text can show the lines around each match, list just the
  matching files with how many matches each has, and page through long
  results.
- The agent no longer tries to solve CAPTCHAs through the browser console.
  On websites the console refuses code that reaches into a CAPTCHA, and any
  code while one is showing, and the agent is told to solve it by looking
  and clicking, or to ask you.
- Web pages, model cards and documents built to keep MinGent busy can't
  stall it: turning them into text stops after a few seconds. A page or
  document then comes through as plain text, and a model card shows without
  its description.
- The chat no longer freezes on a reply with thousands of blank lines, which
  local models sometimes write.
- On the first screen, "Use a cloud model" opens Settings right at the cloud
  API keys, and so do the API key items in the model menu.
- Every clickable control shows the hand pointer, including the model button
  and the switches, lists and buttons in Settings.
- Picking another model while the agent works says that the agent finishes
  the current task with the model it started with, then the new one takes
  over.
- Permission questions say "work folder", like Settings.
- In Full auto, when MinGent turns something down by itself, like sending
  one of your API keys to a website, the agent is told nobody was asked, so
  it doesn't say you declined.
- When you press Stop while a helper works in the background, the agent is
  always told that its report won't come, instead of sometimes getting
  "stopped by the user" as if it were the report.

Version 1.0.9 beta
- CAPTCHA mode no longer makes the page blink while it waits. To see when
  the pictures stop changing, MinGent now watches the browser's own screen
  stream instead of taking cropped screenshots, which flashed the page. It
  waits just as long as before. On screens scaled to about 250% or more,
  the zoomed picture the agent looks at after each round is cut from a
  normal screenshot as well; on other screens it is still drawn at twice
  the size so it stays as sharp, which shows as one blink per round.
- CAPTCHA mode recognizes puzzles from more providers, such as Yandex
  SmartCaptcha, Tencent, MTCaptcha and GeeTest, and Arkose puzzles that a
  site serves from its own address.
- Text CAPTCHAs: in CAPTCHA mode the agent types the characters it reads
  into the answer box. With CAPTCHA mode off, typing into one asks you
  first, the same as clicking any other CAPTCHA.
- A CAPTCHA that sits inside the page, like a text picture or a GeeTest
  slider, comes as a zoomed second picture next to the screenshot of the
  page.
- hCaptcha's pages and Arkose's rounds no longer use up the tries within
  one attempt: the agent gets ten answers for hCaptcha and fifteen for
  Arkose before it hands the CAPTCHA to you.
- The first time the agent meets a kind of puzzle (pages, rounds, a slider,
  press and hold), it is told how that kind works.
- The agent's pointer and the outline of the program it uses now show in
  your screenshots and screen recordings. They still stay out of the
  agent's own screenshots.

Version 1.0.8 beta
- CAPTCHA mode is much faster. The agent clicks all the picture tiles in
  one go, and MinGent waits only until the pictures stop changing (about a
  second) before the agent looks again; after Verify it waits for the next
  puzzle. A picture puzzle that took about a minute takes a few seconds.
  The five tries now count answers sent with Verify, not looks.
- Commands in Auto ask in more cases where your files could be lost:
  deleting even a single file outside the work folder (except in the temp
  folder), replacing or emptying an existing file there (Set-Content,
  Out-File, >, or copying, downloading or unpacking over it), moving files
  out of folders outside it, and git commands that throw away changes git
  hasn't saved (git checkout of a file, git restore, git stash drop).
  MinGent now follows cd, pushd and Set-Location before a delete, so
  "cd ..; Remove-Item -Recurse old" asks, and so do deletes whose target is
  worked out while they run. Writing a new file outside the work folder
  still doesn't ask.
- The agent asks before changing files that hold passwords, keys or tokens
  (.npmrc, .git-credentials, the .ssh folder, private keys), also in Auto.
- Deleting with a patch asks like delete_file outside the work folder, and
  a file the Recycle Bin can't take is kept instead of deleted for good.
  Deleting through a link checks where the link really points.
- With a file open straight from Documents, Desktop or Downloads, the agent
  works in Documents\MinGent Files instead of the whole folder.
- Switching from Ask to Auto while a question waits no longer approves a
  risky one, such as a delete outside the work folder or a clipboard paste.
- Explore helpers can't change files, and the agent can stop helpers again
  (in 1.0.7 it couldn't).
- Browser: clicking a pay, buy or delete-account control by its ref asks
  like clicking it by position (controls made of div, span or role=link
  slipped through). Typing into a field checks where the cursor really
  lands, so a click that moves it into a password or card field types
  nothing. browser_read shows content in web components and links in SVG
  maps, and localhost:5500/index.html opens as a web page, not a file.
- The browser console refuses code that keeps a page method under a
  computed name and calls it later.
- Documents: a table row taller than a page continues on the next PDF
  pages and slides instead of losing text, and in Word long rows can break
  across pages. A spreadsheet formula with a missing bracket or quote is
  saved as text with a note, so Excel doesn't have to repair the file, and
  semicolons between arguments become commas.
- A UTF-8 file with a few bad bytes opens as UTF-8 with those bytes marked
  (saving asks first), instead of as ANSI with garbled accents. A tab too
  large for the agent is refused by its tools instead of read as empty.
- A checklist left over from an earlier task no longer pulls the agent back
  to it in a later turn about something else.
- Actions you confirm while the agent stops (open a chat, delete all chats,
  wipe the browser) all run, in order, instead of only the last one.
- A chat brought back from the archive is no longer pruned at once as one
  of the oldest, and opening an archived chat while the agent works brings
  it back only if you choose to stop the agent.
- Settings changes are kept when you install an update from Settings, and
  updates refuse to unpack into a personal folder (MinGent.exe straight in
  Downloads, say).
- Smaller fixes: the browser console keeps its height, Esc in the chat
  search clears it, the archive says when it is empty and its button is
  reachable by keyboard, a draft keeps its attachments when you switch
  chats, and text boxes no longer cover the frame for dropped files.
- Shorter, plainer text in Settings, the chat panel, the update window and
  the model library.

Version 1.0.7 beta
- Check for updates: "What's new" opens the release notes and keeps the
  update window open, so Install is still there when you come back.
- A command the agent types in a terminal, also in a session on a server
  ("Run a command on example.com"), says what it is for in the agent's own
  words, like the commands it runs itself. When the agent gives no
  description, MinGent now writes one for many more server commands:
  docker and docker compose, databases (mysql, psql, sqlite3), the firewall
  (ufw), certbot, pm2, nginx, crontab, users and passwords, reboot and
  shutdown. "exit" in a session on a server says that it disconnects.
- Stopping the independent review works. "Stop the reviewer", "skip the
  review", "no need for a review" and the like stop a review that is
  running, or keep one from starting. Asked in other words, the agent can
  now stop it for you. It can't stop the automatic review on its own.
- CAPTCHA mode: picking several picture tiles in one step also works on
  Google's own CAPTCHA page, the one Google shows instead of search results,
  and the clicks there count toward the five tries.
- A chat's "..." menu no longer has "Delete all chats". It is in
  Settings > Privacy, where it also deletes archived chats.

Version 1.0.6 beta
- The Auto switch: only the switch itself turns Auto on or off. Clicking
  its name or the arrow opens the menu of Auto modes, and the pointer is a
  hand over all of it.
- The window title is MinGent, not the name of the open chat.
- Settings and the other dialogs open without a white flash.
- The sidebar: the open chat stands out clearly from the one under the
  pointer, long chat names fade out instead of ending in "...", and a "..."
  button with Rename and Delete replaces the trash can.
- Files dropped anywhere on the chat are attached to your message, several
  at a time, with a frame that shows where they go. Dropped on Notes, text
  files open there as before, and PDFs, pictures, documents and folders are
  attached to the chat instead of asking about each "binary file".
- The agent can close the browser's console when it is done with it, or
  when you ask. A console you opened or typed in stays open unless you ask,
  and closing the browser pane also closes a console the agent opened.
- Built-in engine: a model whose template names its own thinking levels gets
  exactly those in the thinking menu, and Off when the template can switch
  thinking off. Qwen 3.8 shows Off, Low, Medium and Extra high (it has no
  plain High).
- Every command MinGent asks about says in plain words what it does. When
  the model gives no description, or only "Run a command", MinGent writes
  one from the command itself ("In src: install the project's packages,
  then run the npm script build"). Commands typed in a terminal get the
  same line.
- Telling the agent to stop in words ("stop", "quit working on this now",
  "that's enough") works like you mean it: no independent review starts
  afterwards, a review that is running is stopped, helpers working in the
  background stop too, and the checklist no longer pushes the agent to carry
  on. A review report that arrives anyway only tells you what it found.
- Text the agent writes before it carries on working no longer disappears
  into the steps: anything longer than a short note ("Let me check the
  file") stays visible in the chat where it was written.
- Answers show how fast the model wrote them, next to Copy: tokens per
  second and the time to the first token, over all the steps of that turn.
  It works for every model, so the built-in engine and LM Studio can be
  compared on the same PC. "About" marks an estimate, when a server doesn't
  report its token count.
- When Google answers a search with a CAPTCHA, MinGent asks you to solve it
  in the browser pane and carries on with Google once you're through.
  "Skip Google" searches with Bing instead and doesn't ask again for 30
  minutes. With CAPTCHA mode on, the agent tries it itself first and asks
  you after five tries that fail.
- CAPTCHA mode is quicker: the agent's screenshots zoom in on the CAPTCHA,
  it can pick several picture tiles in one step, and it sees the CAPTCHA
  again right after, without a separate screenshot step. It now gets five
  tries instead of three.
- Experimental sandbox for the agent's commands, in Settings > Safety (off
  by default). Commands run with low rights: they can read files and use the
  internet, but can change files only in the work folder (not its .git
  folder) and in MinGent's own temp and cache folders, can't change other
  programs or settings, and can't read MinGent's settings, keys or chats. A
  command runs outside the sandbox only when you allow it, or in Full auto.
- Programs you opened yourself, in Settings > Agent (off by default): the
  agent can ask to use a program that was already open. You decide for each
  program, once in each chat, also in Full auto. Browsers, File Explorer,
  terminals and code editors can only be looked at, and mail, chat,
  password managers, money and remote-access programs are never offered.
- Chats can be archived from their "..." menu. They leave the list but stay
  on your PC, under "Archived chats" at the bottom of the list, and opening
  one moves it back.
- Clicking Auto while its menu is open closes the menu.
- The frame that shows where dropped files go no longer leaves dark corners
  around the message box.
- The agent's window names (w1, w2...) stay the same for the whole chat
  instead of changing when another window comes to the front, so it can't
  mix up two programs.
- Sturdier agent loop:
  - a tool that fails in an unexpected way no longer ends the turn; the
    agent hears what went wrong and carries on.
  - a chat that was cut off in the middle of a step (MinGent closed or
    crashed) continues instead of getting an error from the model's server.
  - answering one of the agent's questions, or its plan, with "stop" stops
    the work, like saying it in the chat.
  - telling it to stop is understood more carefully: "add a stop button" or
    "stop the timer at zero" are tasks, not a request to stop.
  - when the automatic review can't finish, the agent gives its answer
    instead of waiting for it.
  - files a background helper changed are reviewed too.
  - pressing Stop while MinGent asks for your OK ends the turn without
    telling the agent you said no.
  - a message you send while a review runs reaches the agent as a message of
    its own.
  - on the last step of a turn the model still sees its tools but can't call
    them, so local models keep their cache and answer sooner.

Version 1.0.5 beta
- Turning on Full auto with a local model, or picking a local model while
  Full auto is on, says that smaller models are easier for a web page to
  trick, and that a frontier model such as Claude, GPT or Gemini is the
  safer choice for Full auto.
- The agent makes PDF, Word, PowerPoint and Excel files with MinGent's own
  writer instead of installing reportlab, python-docx and the like. The
  first time in a chat that it tries to install such a library or run a
  converter like pandoc, LibreOffice or wkhtmltopdf, MinGent points it to
  the built-in way; if you asked for that tool, or want something the
  built-in writer can't do, it can run the command again.
- For scripts the agent uses what is on the PC: Python only when it is
  installed, otherwise PowerShell, and C# compiled with the compiler in
  Windows for heavy work. When that compiler rejects newer C# syntax,
  MinGent says what to write instead.
- The built-in browser has a console under the page: "Console" in its new
  "..." menu, or Ctrl+Shift+J. It shows the page's errors, warnings and
  logs, the code the agent runs and what came back, and you can run
  JavaScript there yourself. "Developer tools" in the same menu, or F12,
  opens Edge's developer tools.
- The agent can read the console and run JavaScript in the page to debug
  it, and after each browser step it hears about new errors on pages from
  this PC. A website's console is only read once you or the agent ask,
  since some sites turn away browsers that read it.
- Running console code asks first, in Auto mode too, unless you switch off
  the new "Running code in the browser console" row in Settings > Safety,
  which warns before it goes off. On websites the question is red. MinGent
  refuses console code that clicks, types, presses keys, scrolls, submits,
  opens pages or windows, or hides what it runs, so the agent does those
  with the normal browser tools and their checks. On websites it also
  refuses network requests and reading cookies, storage or form fields.
- Sound analysis goes deeper when the agent asks for it: beat and bar
  times, hits sorted into low, mid and high, the notes of a melody with a
  guess at the key, and the sections of a song. Long lists are saved to a
  .csv file in the workspace, so the chat gets a short answer.
- The agent can line up two sound files: where one starts in the other, to
  the sample when they share audio, and whether they drift apart over time,
  with their tempo, key and loudness side by side.
- For sound the agent makes in code, a listening report says how it starts
  and ends, whether notes click as they change or a loop clicks at the
  seam, the pitch and tuning, whether the tone is pure, square, triangle or
  sawtooth-like, aliasing from waves made without band-limiting, and
  clipping, DC offset or levels that are too loud or quiet.
- Settings > General > "Check for updates" asks GitHub for the newest
  release, only when you click it. MinGent installs a release only if both
  release keys pinned in this version signed it (a key in the TPM chip of
  the developer's PC and a security key that has to be touched), checks
  the download against the signed SHA-256, and builds it with the C#
  compiler in Windows. Then MinGent closes, the new version takes its
  place in the same folder, and it opens again. If it fails to start, the
  old version is put back. A release without both signatures is never
  installed.
- With two or more graphics cards, the model library adds up the memory of
  the cards the engine uses when it suggests sizes and says what fits, and
  its header names them all with their total memory. The engine already
  spread models over every card; MinGent only counted the biggest.
- On a laptop, the graphics card counts ahead of graphics built into the
  processor, even when the built-in one reports more memory. A PC with an
  older NVIDIA card next to a newer one gets the Vulkan build, which runs
  on both.

Version 1.0.4 beta
- Local models that always think, such as DeepSeek R1 and its distills,
  QwQ and the Qwen 3 Thinking-2507 models, no longer offer Off on the
  Thinking chip. The built-in engine can't stop their thinking, so Off let
  them think without any limit. Low is now their fastest level, and Off
  picked for another model counts as Low for them. Summarizing a long chat

Version 1.0 beta - first public release
- An AI agent for Windows that works in your files, runs commands, searches
  the web, uses its own built-in browser and tests the desktop programs it
  builds, showing every step. It has its own notepad (Notes) for your notes
  and for the files it works on.
- Runs models on your own PC with the built-in llama.cpp engine, pinned to
  llama.cpp 0.7.0 and checked against SHA-256 checksums built into MinGent.
  Newer llama.cpp releases are offered only if you switch that on. Claude,
  OpenAI and Gemini work with your own API key, and LM Studio, Ollama and
  other OpenAI-compatible servers work too.
- No dependency tree: one folder of C# that Build-MinGent.bat compiles with
  the C# compiler that is part of Windows. No packages, plugins, MCP servers,
  installer, updater or telemetry.
- Ask, Auto and Full auto. Auto still asks before installing software,
  starting other programs, deleting widely, system changes, touching
  credentials, publishing, payments or account actions, and downloading
  programs in the browser; Settings > Safety sets which. In every mode its
  file tools never write into Windows, Program Files or its own data, and
  sending your saved API keys to a website asks first (Full auto refuses).
- Undo for every reply that changed files with the agent's file tools. Files
  it deletes with its delete tool go to the Recycle Bin, and Undo brings them
  back. Changes made by commands can't be undone.
- Runs that go in circles (the same failing call, plan research that never
  ends, checklist updates without work) are stopped after a few steps and the
  agent says where it got stuck.
- Model library: search Hugging Face, see which size fits your graphics card
  and how much memory a long chat needs, download several models at once
  (checked against Hugging Face's SHA-256), and pick the folder they go to.
- Settings > Agent > Tools: switch tool groups on or off and see how much of
  the model's context each one takes.
- Settings > Privacy: offline mode, a list of every internet address MinGent
  connected to, optional connection and error logs (off by default), and
  "Erase everything", which overwrites what MinGent stored with random data
  before deleting it and keeps the engine and models unless you choose.
- Dark with a green accent. Settings > General switches the theme and accent
  color, and Reset puts every setting back to how MinGent comes.
- Reads and writes Word, Excel, PowerPoint and PDF files, reads YouTube
  transcripts, typesets math, and keeps your Notes tabs safe across restarts.

Known limits in this beta
- Offline mode stops MinGent's own connections; it is not a firewall, so a
  program that goes online by itself still can.
- YouTube transcripts come from YouTube's own pages and can stop working
  when YouTube changes them.
- Letting the agent try CAPTCHAs (Settings > Agent) is an experiment and is
  off by default.
- The agent controls only programs it started itself (and ones Windows opens
  for its commands); everything else on your PC stays off limits.
