MinGent - what changed
======================

Version 1.0.5 beta
- Turning on Full auto with a local model, or picking a local model while
  Full auto is on, says that smaller models are easier for a web page to
  trick, and that a frontier model such as Claude, GPT or Gemini is the
  safer choice for Full auto.
- The agent makes PDF, Word, PowerPoint and Excel files with MinGent's own
  writer instead of installing reportlab, python-docx and the like. The
  first time in a chat that it tries to install such a library or run a
  converter like pandoc, LibreOffice or wkhtmltopdf, MinGent points it to
  the built-in way; if you asked for that tool, or want something the
  built-in writer can't do, it can run the command again.
- For scripts the agent uses what is on the PC: Python only when it is
  installed, otherwise PowerShell, and C# compiled with the compiler in
  Windows for heavy work. When that compiler rejects newer C# syntax,
  MinGent says what to write instead.
- The built-in browser has a console under the page: "Console" in its new
  "..." menu, or Ctrl+Shift+J. It shows the page's errors, warnings and
  logs, the code the agent runs and what came back, and you can run
  JavaScript there yourself. "Developer tools" in the same menu, or F12,
  opens Edge's developer tools.
- The agent can read the console and run JavaScript in the page to debug
  it, and after each browser step it hears about new errors on pages from
  this PC. A website's console is only read once you or the agent ask,
  since some sites turn away browsers that read it.
- Running console code asks first, in Auto mode too, unless you switch off
  the new "Running code in the browser console" row in Settings > Safety,
  which warns before it goes off. On websites the question is red. MinGent
  refuses console code that clicks, types, presses keys, scrolls, submits,
  opens pages or windows, or hides what it runs, so the agent does those
  with the normal browser tools and their checks. On websites it also
  refuses network requests and reading cookies, storage or form fields.
- Sound analysis goes deeper when the agent asks for it: beat and bar
  times, hits sorted into low, mid and high, the notes of a melody with a
  guess at the key, and the sections of a song. Long lists are saved to a
  .csv file in the workspace, so the chat gets a short answer.
- The agent can line up two sound files: where one starts in the other, to
  the sample when they share audio, and whether they drift apart over time,
  with their tempo, key and loudness side by side.
- For sound the agent makes in code, a listening report says how it starts
  and ends, whether notes click as they change or a loop clicks at the
  seam, the pitch and tuning, whether the tone is pure, square, triangle or
  sawtooth-like, aliasing from waves made without band-limiting, and
  clipping, DC offset or levels that are too loud or quiet.
- Settings > General > "Check for updates" asks GitHub for the newest
  release, only when you click it. MinGent installs a release only if both
  release keys pinned in this version signed it (a key in the TPM chip of
  the developer's PC and a security key that has to be touched), checks
  the download against the signed SHA-256, and builds it with the C#
  compiler in Windows. Then MinGent closes, the new version takes its
  place in the same folder, and it opens again. If it fails to start, the
  old version is put back. A release without both signatures is never
  installed.
- With two or more graphics cards, the model library adds up the memory of
  the cards the engine uses when it suggests sizes and says what fits, and
  its header names them all with their total memory. The engine already
  spread models over every card; MinGent only counted the biggest.
- On a laptop, the graphics card counts ahead of graphics built into the
  processor, even when the built-in one reports more memory. A PC with an
  older NVIDIA card next to a newer one gets the Vulkan build, which runs
  on both.

Version 1.0.4 beta
- Local models that always think, such as DeepSeek R1 and its distills,
  QwQ and the Qwen 3 Thinking-2507 models, no longer offer Off on the
  Thinking chip. The built-in engine can't stop their thinking, so Off let
  them think without any limit. Low is now their fastest level, and Off
  picked for another model counts as Low for them. Summarizing a long chat
  uses their lowest level too, so long thinking no longer crowds out the
  summary.
- The answer row of a question card shows a blinking cursor before you
  click it, so it reads as a place to type, not a button.
- The cursor in the search box of the long model list sits where typing
  starts, also before you type. In the message box and the answer row, the
  grey hint text starts at the cursor.

Version 1.0.3 beta
- Attachments: files you attach, drop or paste show as cards with their
  type and size, pictures as small previews, each with a remove button.
  Folders can be attached too. Sent messages show them above the text:
  click a picture to see it larger, a text file to open it in Notes, a
  document to open it, and anything else to show it in its folder.
  Reopened chats keep the cards. The agent gets the full path of
  everything attached, also of pictures that came from a file.
- Ctrl+V and Shift+Insert in the message box attach a screenshot, a
  picture copied from a browser or files copied in Explorer. Copied text
  and spreadsheet cells still paste as text.
- Files can be sent while the agent works, and queued, edited and resent
  messages keep their attachments. When the model can't see pictures, a
  notice says so instead of leaving them out silently.
- The agent can open its own terminal window (Windows Terminal, or a
  console where that is missing) and type commands there while you watch,
  for example to manage your server over ssh. MinGent checks the command
  line before Enter and before any other key or click that could run it,
  the same way it checks the agent's other commands, and clears a line you
  refuse. On a server, commands that only look around run in Auto mode and
  anything else asks, unless you switch off the new "Changes on servers
  over ssh" row in Settings > Safety. Reading password, key or token files
  on a server asks like it does on this PC. Terminals you opened yourself
  stay off limits.
- run_command checks "ssh host command" the same way.
- Helpers keep working in the background when you send a message, and the
  agent answers you meanwhile. Their reports are added when they are done,
  and the agent waits for them before it finishes. Each helper step is a
  row under the helper card, live while it works and after the chat is
  reopened. Stop ends helpers in the background too.
- Compacting a long chat gives the summary everything you asked for, your
  answers to the agent's questions, the plan you approved, reports from
  helpers and the review, and the checklist. When it doesn't all fit, the
  agent's own steps are shortened and left out first.
- Plain waits (Start-Sleep, timeout, sleep, ping to this PC) run inside
  MinGent instead of as programs, so they no longer ask after the chat has
  read web content. Ask mode still asks before a wait.
- The answer row of a question card and the search box of the long model
  list show a blinking cursor and a highlighted border while they have the
  focus. A number typed in the answer row picks that option, unless an
  option's text is that number.
- Temporary chats: closing MinGent asks about the chat's unsaved notes, as
  leaving it does, instead of bringing them back the next time. After a
  crash, the built-in browser's history is cleared at the next start.
- Command scripts a crash left in %TEMP%\MinGent are erased at the next
  start instead of a day later.
- If Windows can't encrypt an API key, Settings doesn't save it, instead of
  storing it unencrypted.
- Offline mode also refuses ping, nslookup, Resolve-DnsName,
  Test-NetConnection, tracert, mosh and rsync aimed at the internet.
  Connections also lists where a failed request was redirected.
- "Try again" after the chat was summarized continues the task instead of
  sending the summarized message again.

Version 1.0.2 beta
- Web search happens in the built-in browser, where you can watch it: Google
  first, then Bing, then DuckDuckGo when Google shows a bot check or has
  nothing. Google hides each result's address behind its own link, so
  MinGent looks up the real address and the agent gets normal links it can
  read and cite. Reading a page from its address stays a direct download.
  With the browser off, searches go to DuckDuckGo and Bing directly, as
  before.
- Sound files: the agent can measure a WAV, MP3, M4A, FLAC, WMA or other
  sound file, or the sound of a video: loudness (LUFS), peaks and clipping,
  silences, background noise, stereo, frequency balance, the strongest
  tones, pitch, tempo and a rough key, with a waveform and a spectrogram for
  models that can see images. MinGent reads WAV and AIFF itself and other
  formats with the decoders built into Windows; nothing is downloaded.
- API keys are checked as soon as you paste them, and Settings says whether
  the key works or why it was rejected. A key pasted in another provider's
  row is not sent anywhere; Settings says which row it belongs in. Change
  and Remove replace or delete a saved key, and each key has a link to the
  page where you make one (Claude's now goes to platform.claude.com).
- OpenRouter as a provider: one key for models from many makers. MinGent
  lists the models that can use tools, most popular first, with their
  prices, and passes the Thinking level on. When the account can't pay for
  a long answer, MinGent asks again with the length it can pay for.
- The model menu checks for models again each time you open it and updates
  the list while it is open. Its "All N models..." list has a search box.
- Model library: icons show what a model can do, also in the Download list
  before you download it: a hammer for tool use, an eye for vision, a bulb
  for thinking, and a red warning when its chat template has no tool calls.
  Hover an icon to see what it means. MinGent reads this from the model's
  chat template and files on Hugging Face.
- Error messages and notices in the chat can be selected and copied, and
  error dialogs have a Copy button (Ctrl+C works too).
- Messages you send while the agent works wait at the bottom of the chat.
  When the agent reads one, its steps so far fold away above your message
  and what it says back shows under it in the open, instead of inside the
  closed list of steps.
- Questions from the agent: type your own answer in the last row of the
  question card instead of the message box. A change you type there for an
  offered plan goes out as a new message.
- Keys: the agent can hold keys down (up to 10 seconds at a time) and press
  several at once (Shift+W, W+D) in the browser and in programs it started,
  for games and the like. Keys can be named the way Windows and browsers
  name them (Minus, Equal, Comma, KeyW, Digit5, OemPeriod).
- A pointer in your accent color shows where the agent points, clicks, drags
  and scrolls, in the browser and in desktop programs. It lets clicks
  through and never shows up in the agent's screenshots.
- Side by side: the outline and "MinGent" tag of the program the agent uses
  are drawn inside its window when it touches the screen edges, so they no
  longer hide behind MinGent's own window.
- Auto mode: plain waits (Start-Sleep, timeout, ping to this PC) no longer
  ask after the chat has read web content.
- YouTube transcripts load more often: when the video page's caption links
  need a token, MinGent asks YouTube's player the way the Android app does.

Version 1.0.1 beta
- Web search leaves out results that have nothing to do with the query.
  Search engines sometimes answer automated searches with a bot check or
  with unrelated pages; MinGent now tries DuckDuckGo, DuckDuckGo Lite and
  Bing in turn, and when none of them gives related results it says so and
  the agent searches in the built-in browser instead. Queries with subscript
  or superscript digits, full-width letters, or Lao, Khmer or Burmese text
  match the results that contain them, and when an engine really has no
  results, the agent is told that, so it tries other words.
- The reviewer and general helpers use the built-in browser to check web
  pages; a reviewer only opens pages on this PC or the local network there.
  MinGent doesn't let a helper open Chrome, Edge or other programs' windows,
  which it couldn't see anyway. Helpers are told which developer tools are
  on the PATH, so they don't spend steps looking for Node or Python. Reviews
  run one at a time.
- Opening a file with another program by running its path (like .\index.html),
  Process.Start, Python's webbrowser and rundll32 url.dll now ask first in
  Auto mode, like Start-Process already did. "code --version", "devenv.com
  /build" and PowerShell's "write" no longer ask.
- Desktop programs: MinGent no longer asks about a program from behind its
  window. A program the agent started goes side by side with MinGent before
  the question, and for other programs MinGent comes to the front to ask.
- A command that both opens a program and does something riskier (installs,
  deletes, touches credentials) is now asked about as the riskier one.
- Changing the context length or Context memory of the built-in engine takes
  effect on the next message instead of after restarting MinGent.
- Settings: the theme and accent color change as soon as you click them, and
  Cancel puts the old look back. The mouse wheel scrolls the page also when
  the pointer is over a text box. Cancel keeps none of your changes, also
  after you said no to stopping a download for offline mode.

Version 1.0 beta - first public release
- An AI agent for Windows that works in your files, runs commands, searches
  the web, uses its own built-in browser and tests the desktop programs it
  builds, showing every step. It has its own notepad (Notes) for your notes
  and for the files it works on.
- Runs models on your own PC with the built-in llama.cpp engine, pinned to
  llama.cpp 0.7.0 and checked against SHA-256 checksums built into MinGent.
  Newer llama.cpp releases are offered only if you switch that on. Claude,
  OpenAI and Gemini work with your own API key, and LM Studio, Ollama and
  other OpenAI-compatible servers work too.
- No dependency tree: one folder of C# that Build-MinGent.bat compiles with
  the C# compiler that is part of Windows. No packages, plugins, MCP servers,
  installer, updater or telemetry.
- Ask, Auto and Full auto. Auto still asks before installing software,
  starting other programs, deleting widely, system changes, touching
  credentials, publishing, payments or account actions, and downloading
  programs in the browser; Settings > Safety sets which. In every mode its
  file tools never write into Windows, Program Files or its own data, and
  sending your saved API keys to a website asks first (Full auto refuses).
- Undo for every reply that changed files with the agent's file tools. Files
  it deletes with its delete tool go to the Recycle Bin, and Undo brings them
  back. Changes made by commands can't be undone.
- Runs that go in circles (the same failing call, plan research that never
  ends, checklist updates without work) are stopped after a few steps and the
  agent says where it got stuck.
- Model library: search Hugging Face, see which size fits your graphics card
  and how much memory a long chat needs, download several models at once
  (checked against Hugging Face's SHA-256), and pick the folder they go to.
- Settings > Agent > Tools: switch tool groups on or off and see how much of
  the model's context each one takes.
- Settings > Privacy: offline mode, a list of every internet address MinGent
  connected to, optional connection and error logs (off by default), and
  "Erase everything", which overwrites what MinGent stored with random data
  before deleting it and keeps the engine and models unless you choose.
- Dark with a green accent. Settings > General switches the theme and accent
  color, and Reset puts every setting back to how MinGent comes.
- Reads and writes Word, Excel, PowerPoint and PDF files, reads YouTube
  transcripts, typesets math, and keeps your Notes tabs safe across restarts.

Known limits in this beta
- Offline mode stops MinGent's own connections; it is not a firewall, so a
  program that goes online by itself still can.
- YouTube transcripts come from YouTube's own pages and can stop working
  when YouTube changes them.
- Letting the agent try CAPTCHAs (Settings > Agent) is an experiment and is
  off by default.
- The agent controls only programs it started itself (and ones Windows opens
  for its commands); everything else on your PC stays off limits.
